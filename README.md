
# PixelShield

A lightweight Windows blackout utility built with OLED users in mind.

## Who is PixelShield for?

PixelShield is designed primarily for people using **OLED displays** who want a simple way to turn their screens completely black when their computer is idle.

OLED pixels can turn off when displaying pure black, making PixelShield useful for reducing unnecessary pixel usage while you're away from your computer.

It's also useful for anyone who wants an automatic blackout screen for their PC.

## Features

- Pure black (#000000) screen overlay.
- Supports multiple displays.
- Hides the mouse cursor during blackout.
- Automatically activates after a period of inactivity.
- Restores the screen when activity is detected.
- Optional monitor brightness reduction where supported.
- Designed to use minimal system resources.
- Automatically starts with Windows.
